# Earth Reborn editorial procedure

This pass reviews the four release manuscripts, checks the series structure and continuity, and applies conservative refinements to the Markdown editions. The author confirmed on 23 October 2026 that Fall of the Empire is intended as a distinct third novel.

1. Query Hath0r and Author MCP first. Where the index cannot retrieve the current release paths, inspect the current local files and distinguish them from indexed historical versions.
2. Preserve all original manuscripts and existing binary editions. Save exact pre-edit Markdown copies before changing release text.
3. Compare chapter inventories and overlapping text before assuming that the release labels establish separate novels.
4. Use the narrative itself as evidence. Treat synopses, added recaps, and earlier release-note claims as fallible. Do not invent explanations for conflicting identities or move chapter boundaries without identifying the editorial consequences.
5. Apply only reviewed spelling corrections and targeted prose edits. Do not globally replace ambiguous homophones or character names. Record all changes in unified diffs.
6. Separate documented findings from proposed structural revisions. A proposed trilogy division is not an approved release master.
7. Verify the changed files against their snapshots, preserve chapter order, and publish the actual scope and unresolved issues. Markdown revisions do not update DOCX or PDF editions; those require a subsequent synchronized export and layout review.

This is a structural audit and targeted refinement pass, not certification that every sentence of the approximately 404,000 supplied manuscript words has received a full line edit.
