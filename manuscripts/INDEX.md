# Author Manuscripts Index

Welcome to the Author Manuscripts repository. This repository stores text manuscripts, chapter drafts, outlines, lore, and notes.

> **CRITICAL ARCHITECTURAL RULE**: There is NO website or web application for Books. This repository is strictly for text documents.

## Directory Structure

- `manuscripts/`: Book drafts, chapter text, and full manuscript files.
- `outlines/`: Story arcs, chapter-by-chapter breakdowns, and synopses.
- `worldbuilding/`: World rules, lore bibles, timelines, factions, and maps (text descriptions).
- `characters/`: Character profiles, arcs, relationships, and voice notes.
- `notes/`: Research notes, ideation memos, and editorial feedback.

## Knowledge Access & Air Traffic Control

All documents in this repository are indexed and served via **Author-MCP** (the root MCP server and Air Traffic Control for the Author project).

- MCP Server: `http://127.0.0.1:18083`
- Tool: `search_author_knowledge`
- Tool: `get_author_document`
